# A/C 协议修订 02：资源止损与结果决策规则

- **关联**：原协议 `experiments/ac_v1/protocol.md`（冻结 `8484f5fb`）、
  修订 01 `protocol_amendment_01.md`（`a59f4a76`）
- **生效版本**：`ac_v1 + amendment_01 + amendment_02`；**首次正式运行前生效**
- **Manifest 要求**：三份协议文件的哈希（`protocol_hash`、`protocol_amendment_01_hash`、
  `protocol_amendment_02_hash`）**全部纳入**执行清单

## 0 先分清三个问题（不可互相替代）

| 问题 | 判定内容 | 不通过的后果 |
|---|---|---|
| 实验是否有效？ | 两臂是否真用了约定输入/模型/参数；所有案例是否都留记录 | **不能解释实验结果** |
| Agent 是否有增量价值？ | C 是否解决了 A 没解决的问题，且能用新增证据与轨迹解释为什么 | **不能宣称 Agent 有用** |
| 增量是否值得代价？ | 改善是否抵得过额外调用、token、延迟与可能增加的人工转交 | 即使有改善，也**不代表值得保留** |

## 规则 1：封顶基础设施范围

只完成**已经确定**的必要事项：`INVALID_SCHEMA` 的责任边界与测试、缺失的真实超时路径测试、
评分汇总与已知答案测试、端到端框架自检。

**不新增 Agent 能力**，不泛化为通用 Agent 框架，不为追求更漂亮的结果不断扩建评测设施。

## 规则 2：正式实验只按预先声明的口径解释

先通过**真实模型的独立冒烟测试**，再运行**一轮冻结的 50 案例 A/C 对照**；正式运行产物
**不可覆盖**。

只有出现**明确、可复现的技术缺陷导致实验本身无效**时，才允许修复后**创建新版本重新运行**。
**不得**因为指标不理想、差异不显著或结果不符合预期而重跑。

## 规则 3：保留 Agent 需要可追溯的业务增益

不能只凭总体准确率的一次波动，**也不能只挑出实际进入子图的成功案例**。

保留 Agent 作为项目核心能力，至少应观察到**跨多个案例、多个预定义动态取数模式的可重复改善**，
且改善体现在**主要输出**（分诊队列／优先级、证据包质量），并能追溯到
**C 获取了哪些 A 未获得的相关证据、这些证据如何改变了结果**。

同时检查：50 案例整体表现、安全转人工、草稿质量、工具调用量、成本与延迟。
**以上是工程决策标准，不是统计显著性检验**，也不声称小样本足以证明普遍因果关系。

**判断对象**：主要是**全部 50 案例的配对结果**，以及**冻结的 Agent-needed 子集**。
实际进入子图的案例**只用于解释机制与路由表现**，不得被单独挑出来作为胜利证据——
路由有没有识别出需要动态取数的案例，本身就是级联系统要接受检验的一部分。

**"可重复改善"的定义（防事后解释）**：本轮所称的可重复改善，是指**同类业务收益在不同案例
及多个预定义动态取数模式中反复出现，并有对应的案例级证据链支持**；
**不指对同一批案例重复运行**。该判断属于**工程决策证据**，
**不构成统计显著性或跨运行复现性的声明**。

**逐案例判定口径必须先于结果固定**：正式实验前必须写明
① 每个案例如何判定 C 相对 A 有业务收益（依据什么字段、到什么程度算改善）；
② 最终报告**逐模式**展示哪些结果（每个预定义动态取数模式的案例数、配对差异、证据归因）。
不为此新增复杂数值门槛，但**口径必须先定义**，不能等跑完再挑有利的解释方式。

## 规则 4：没有足够证据，就停止扩建并降级项目叙事

- 若一次**有效**实验后，Agent 的改善**没有形成可追溯、可重复的模式**，或改善**不足以支撑**
  额外成本与复杂性 → **停止扩展 Agent 路线**，项目定位改为
  **"证据驱动的工单分诊工作流"**；
- 若实验有效，但**样本、路由覆盖或评判一致性不足以支持结论** → 也停止扩建，结论写为
  **"本轮探索性实验未能建立 Agent 的增量价值"**，**不写**"已证明 Agent 完全没有价值"；
- 只有**实验本身无效**时，才先判断是否存在值得修复的具体技术问题。
  **不得**以"基础设施还需要更完善"为由无限期推迟业务验证。

## 附：一条边界

止损不意味着"Agent 输了就算失败"，也不意味着"怀疑某个子模块可能有效"可以换来更多开发周期。
**允许保留未解决的问题，但不允许未解决的问题自动获得更多工程预算。**

这个项目最终**可以没有 Agent**，但**不能一直没有对 Agent 的检验结果**。
